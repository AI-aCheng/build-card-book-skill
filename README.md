# build-card-book-skill · 书 → 翻阅式卡片工具书

把一本书 / 一个主题做成「单文件 HTML 翻阅式卡片工具书」的**硬编码技能包**（Hermes/Claude/任意 agent 可用）。

> 米色纸感 + 衬线标题 + 书签色带 + 图书馆 hero 渐变蒙版 + 左右翻页（每主题一张卡）的响应式单文件 HTML，无外部依赖（除可选 hero 图，离线降级）、手机不裁切。

## ✨ 特性

- **硬编码工作流**：填 JSON → 跑脚本 → 自动产出，无需手写 HTML
- **三处自动同步**：目录页 / 导航下拉 / 主题卡 id（#c01..#cN）由脚本统一生成，不会漏改
- **内容详实**：每张卡 = 命题（2-3 句）+ 原文引用（含出处）+ 3 个现实场景 + **怎么用（步骤清单）** + **别踩的坑**
- **双模板**：基础版（米色纸浅色）+ themed 版（深色 ☀/🌙 + 5 套书主题配色，localStorage 持久化）
- **自动自检**：结构闭合 / 占位符残留 / id 对应 / safe center / 箭头分侧 全自动检查

## 🚀 快速开始

```bash
# 1. 填内容 JSON（参考 examples/mao-cards.json）
vim cards.json

# 2. 生成（默认 themed 模板；--basic 用基础模板）
python3 scripts/build_card_book.py cards.json -o 我的卡片书.html

# 3. 自检（全 ✅ 即交付）
python3 scripts/check_card_book.py 我的卡片书.html
```

### cards.json 结构

```json
{
  "书名": "毛泽东选集", "书印单字": "毛", "副标题": "方法论口袋书",
  "导语": "把书读薄。", "关键词": "毛选清单", "公众号名": "AI阿程Harness实录",
  "总览": "一句话总览", "金句": "书中最金的一句", "年代": "1925—1957",
  "使用步骤": ["四步指引，可省略用默认", "...", "...", "..."],
  "卡片": [
    {
      "名": "调查研究", "描述": "目录页一句话",
      "命题": "核心主张（2-3 句）",
      "原文": "书中的原文引用", "出处": "《篇目》(年份)",
      "步骤": ["怎么做 1", "怎么做 2", "怎么做 3"],
      "场景": ["工作与决策场景", "团队与管理场景", "个人成长场景"],
      "避免": "别踩的坑 / 边界提醒"
    }
  ]
}
```

字段说明：`步骤` / `避免` 可省略（卡片自动少两块）；卡片数量不限（目录/导航自动同步）。

## 📦 资产

| 文件 | 说明 |

| `SKILL.md` | 技能定义（触发条件 / 流程 / 防坑清单） |
| `scripts/build_card_book.py` | 生成器：JSON → 单文件 HTML |

| `assets/card-book-template.html` | 基础模板（米色纸浅色） |

| `examples/mao-cards.json` | 完整示例（《毛选》12 张方法论卡，内容详实版） |

## 🐛 已踩过的坑（都固化进脚本/检查器）

1. 封底开标签被替换正则吃掉 → lookahead 以封底开标签为边界
2. 使用方法页 4 步占位符漏替换 → 脚本内置默认四步 + 占位符映射
3. 顶栏遮挡 → `.page` 用 `align-items: safe center`
4. 左右箭头重叠 → `.prev`/`.next` 分侧写 left/right，基类不写
5. 目录/导航/卡片三处不同步 → 脚本统一生成
